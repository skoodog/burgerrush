# Burger Rush Claude Code launch pack

This folder is not the finished game. It is a production brief and Claude Code orchestration pack.

Start with `SETUP.md`, then run Claude Code in auto mode and paste `MASTER_PROMPT.md`.

Included:

- autonomous master build prompt;
- persistent `CLAUDE.md`;
- safe project permission rules;
- nine specialist subagents;
- five reusable project skills;
- detailed Sal/Pep four-presentation and red/blue local-co-op specifications; cute-scary enemy, giant-burger boss, Higgsfield, animation, substrate-footstep, klaxon, projectile-SFX, and music prompts;
- dedicated local co-op character-select specification;
- initial build-status and asset-ledger templates.

## Revision 3 highlights

- Player-facing chefs are **Sal (`S`)** and **Pep (`P`)**.
- Sal and Pep each support **Boy** and **Girl** presentation; both local players may choose the same gender.
- Two local devices join and control separate character-select panels by keyboard or controller.
- Player 1 always has red striping and toque lettering; Player 2 always has blue, independent of chef identity or presentation.
- Occupied Sal/Pep choices swap identities while preserving each player's presentation, device, and slot color.
- A dedicated local co-op input agent, validation skill, art matrix, disconnect/rebind flow, replay schema, and acceptance-test suite are included.
- Revision 2's mandatory bilingual boss warning, sibling launch, flying burger boss, and unlimited Boss Flight spatulas remain unchanged.
