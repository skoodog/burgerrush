Produce the `$ARGUMENTS` asset family.

1. Read `docs/ART_AND_AUDIO_PROMPTS.md`.
2. Inspect available MCP tools and authentication. Never invent a call.
3. Confirm the asset IDs, dimensions, animation states, alpha needs, and gameplay scale from the manifest.
4. Generate a low-cost contact sheet or motion-reference pass first.
5. Select against silhouette clarity, originality, continuity, animation feasibility, and palette.
6. Generate final source media only for the selected direction.
7. Save prompt, model/tool metadata, attempt count, and estimated credits in `docs/ASSET_LEDGER.md`.
8. Process and validate output locally.
9. Keep placeholders available behind the same asset IDs.
10. Run the game and inspect the assets at actual play scale.

For chef/boss families, enforce Sal/Pep sibling continuity across Sal Boy, Sal Girl, Pep Boy and Pep Girl; build exact red/blue accent masks or aligned exports; exclude salt/pepper shakers, include flight poses and dual-spatula firing, and create separate shape-readable pickle, ketchup, mustard, and mayo projectile sheets.
